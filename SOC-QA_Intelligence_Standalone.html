Self-Contained Browser Runtime & Zero-Setup Execution

            

              This application runs 100% locally inside your web browser with zero VS Code or manual server startup required:
            

            

              

                1. Direct Browser Launch: Double-click soc_qa_intelligence_workbench.html (or Launch_SOC_QA_Intelligence.bat in the zip) to open directly in Chrome, Edge, or Firefox.
              

              

                2. Automatic Browser Persistence: All uploaded datasets, SHA-256 provenance records, normalized events, cases, and playbook versions auto-save to local browser storage (0 KB used).
              

              

                3. Portable Snapshot Backup: Export or restore your entire research database as a single .socqa.json file anytime.
